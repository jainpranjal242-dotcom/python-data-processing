# VEDA Technology — Task 9: Python Data Processing

## Objective
Process structured student records and generate useful summary statistics using Python.

## Tools
- Python 3
- Jupyter Notebook

## Features
- Stores structured records using dictionaries inside a list
- Calculates average marks, highest/lowest marks, attendance and age
- Filters high-performing students
- Generates department-wise statistics
- Processes records with performance and attendance status
- Demonstrates reusable functions

## Files
- `Python_Data_Processing_Task9.ipynb` — main Jupyter Notebook
- `student_records.csv` — sample structured dataset
- `requirements.txt` — environment information
- `README.md` — project documentation

## How to Run
1. Install Python 3 and Jupyter Notebook.
2. Open the notebook.
3. Run all cells from top to bottom.
4. Review the summary statistics and processed records.

## Sample Output
- Total records: 10
- Average marks: 83.80
- Highest marks: 95
- Lowest marks: 68
- Average attendance: 87.80%
- Average age: 20.00 years
